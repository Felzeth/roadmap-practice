# Changelog Component

A simple, responsive changelog component built with HTML and CSS. This project focuses on learning positioning and layout in CSS, specifically using Flexbox and absolute positioning to create a timeline-style UI.

Based on the [Changelog Component](https://roadmap.sh/projects/changelog-component) challenge from roadmap.sh.

## How to Run

Open `index.html` in your browser.

```bash
git clone https://github.com/Felzeth/roadmap-practice.git
cd roadmap-practice/changelog-component
open index.html
```

## Features

- Clean, minimalist design
- Vertical timeline layout with dots and connecting lines
- Responsive design (adapts to mobile devices)
- CSS Flexbox and Absolute Positioning
- Custom fonts (Inter)
