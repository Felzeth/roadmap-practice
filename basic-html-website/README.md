# Basic HTML Website

A multi-page website built with semantic HTML only — no CSS, no JavaScript. Focused on proper structure, navigation, and SEO.

Based on the [Basic HTML Website](https://roadmap.sh/projects/basic-html-website) challenge from roadmap.sh.

## How to Run

Open `index.html` in your browser.

```bash
git clone https://github.com/Felzeth/roadmap-practice.git
cd roadmap-practice/basic-html-website
open index.html
```

## Pages

| Page | Description |
|------|-------------|
| [Home](./index.html) | Hero, projects, work experience, education, teacher reviews |
| [Projects](./projects.html) | List of frontend projects |
| [Articles](./articles.html) | Blog articles |
| [Contact](./contact.html) | Contact form with name, email, message |

## What's Included

- Semantic HTML structure (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- Consistent navigation bar across all pages
- SEO meta tags on every page
- Contact form with name, email, and message fields
- Proper heading hierarchy
