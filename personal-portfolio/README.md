# Personal Portfolio

A fully styled, responsive personal portfolio website. Styled version of the Basic HTML Website project using CSS Flexbox, Grid, and media queries.

Based on the [Personal Portfolio](https://roadmap.sh/projects/personal-portfolio) challenge from roadmap.sh.

## How to Run

Open `index.html` in your browser.

```bash
git clone https://github.com/Felzeth/roadmap-practice.git
cd roadmap-practice/personal-portfolio
open index.html
```

## Features

- Responsive layout (desktop 3-column grid → mobile stacked)
- Google Fonts (Inter + Playfair Display)
- CSS Grid for the main three-column section
- Flexbox for header and reviews
- Media queries for mobile breakpoint at 768px
- Styled contact form with focus states
- Consistent navigation across all pages

## Pages

| Page | Description |
|------|-------------|
