# Single-Page CV

A single-page CV (Curriculum Vitae) built with semantic HTML. No CSS, no JavaScript — just clean, accessible markup ready for styling.

This project is based on the [Single-Page CV](https://roadmap.sh/projects/single-page-cv) challenge from roadmap.sh.

## How to Run

Open `index.html` in your browser.

```bash
git clone https://github.com/YOUR_USERNAME/roadmap-projects.git
cd roadmap-projects/single-page-cv
open index.html
```

## What's Included

- Semantic HTML structure (`<header>`, `<main>`, `<section>`, `<article>`, `<address>`)
- SEO meta tags (title, description, keywords, author)
- Open Graph tags for social media sharing
- Favicon link
- Sections: Skills, Education, Experience, Online Profiles

## How to Customize

1. Replace "Your Name" and contact details with your own
2. Update skills, education, and experience sections
3. Add your LinkedIn and GitHub profile links
4. Replace `favicon.png` with your own favicon
5. Update the OG tags in the `<head>` with your real URL and image
