# Custom Dropdown

A custom dropdown menu built with vanilla HTML, CSS, and JavaScript. No frameworks, no libraries.

This project is based on the [Custom Dropdown](https://roadmap.sh/projects/custom-dropdown) challenge from roadmap.sh.

## How to Run

Open `index.html` in your browser.

```bash
git clone https://github.com/Felzeth/roadmap-practice.git
cd roadmap-practice/custom-dropdown
open index.html
```

## Features

- Default state with placeholder text "Select an Item"
- Click to open/close the dropdown
- Shows all options in a list
- Selected item displays with a checkmark
- Clicking outside closes the dropdown
- Keyboard support (Escape to close)
- Arrow rotates when open
